# Ayat

<br />

<img src="https://github.com/Mhadi-1382/ayat/blob/main/static/assets/images/logo/SVG/icon_splash.svg" alt="Ayat" width="120">

<br />

*`Ayat` is an intelligent Quranic web application designed to provide a structured and technology-driven experience for accessing Quranic resources. Developed with a focus on the academic environment, the platform supports both individual use and the management of cultural and Quranic activities within universities.
<br />
<br />
Built on a modular architecture, with a user role management system and intelligent features, Ayat provides an organized and scalable platform for educational, research, and cultural purposes. By offering the Quran, supplications, Hadiths, and supplementary resources alongside tools such as a smart dhikr counter, personalized content recommendations, and administrative dashboards, Ayat serves as a comprehensive digital solution for Quranic engagement.*
